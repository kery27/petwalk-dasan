# 로고 시안 (아직 고르지 않음)

2026-11-14. 가르시아가 "성난 치와와를 로고로" 하자는 추천에 동의해서 만든 시안이다. 두 갈래가 있다.
**아직 고르지 않았고 앱에는 넣지 않았다** — `icons/`와 `manifest.json`은 그대로다.

1. **새로 그린 판** — 도지 동전 풍으로 그린 SVG (이 폴더의 `chi-coin-*.svg`)
2. **사진에 가장자리 처리한 판** — 받은 사진을 그대로 쓴 것 (그림은 저장소에 없음, 아래 참고)

## 1. 새로 그린 판

| 파일 | 무엇 |
|---|---|
| `chi-coin-front.svg` | 정면에서 이를 드러낸 얼굴 (시안 A안·C안) |
| `chi-coin-side.svg` | 옆을 보며 입을 벌린 얼굴 (시안 B안) |

- 두 파일 모두 바탕 없이 동전만 들어 있다(400×400 기준). 시안 보드에서는 노란 바탕 `#f7c84a`(A·B안)와 앱 색 바탕 `#b8563a`(C안)에 올려 봤다.
- 나란히 비교한 보드: [왈슨 화면 시안 캔버스](https://claude.ai/artifact/DbRJMTbicpqPWmeXoPo2JY)(비공개)의 "앱 아이콘 시안 · 으르렁 치와와 동전".

### 그린 방식

- 손으로 쓴 SVG다. 가르시아가 보낸 치와와 사진과 도지 동전 그림은 따라 그리거나 겹쳐 그리지 않았다(사진·밈 그림의 저작권).
  치와와에서는 큰 귀·툭 튀어나온 눈·드러낸 이빨, 동전에서는 굵은 갈색 선·금색 면·두께가 보이는 옆면이라는 특징만 가져왔다.
- 색: 선 `#5a3210`, 동전 테 `#f6c244`, 동전 안 `#ec9c2c`, 동전 옆면 `#c47d1c`, 털 `#f9d05c`, 밝은 털 `#fff2c8`, 귀 안 `#f4a983`, 입 안 `#5c1f16`.

## 2. 사진에 가장자리 처리한 판

가르시아: "이걸 차라리 그냥 엣지처리만 해봐" → 받은 사진(입을 벌리고 옆을 보는 치와와)을 다시 그리지 않고 그대로 써서 넷을 만들었다.

| 안 | 무엇 |
|---|---|
| A 사진 + 테두리 | 배경을 떼고 굵은 갈색 선과 흰 테만 두름 (스티커 느낌) |
| B 색면 + 선 | 색을 여덟 단으로 줄이고 어두운 곳을 잉크처럼 누름 (만화 느낌) |
| C 선만 | 윤곽선과 어두운 면만 갈색 한 색으로 남김 (도장 느낌) |
| D 금화에 넣기 | 금화 색 다섯 단으로 바꿔 1번의 동전에 넣음 |

- **그림 파일은 이 저장소에 넣지 않았다.** 사진이 인터넷에서 가져온 것으로 보이고(왼쪽 아래에 구글 이미지 검색 표시가 있었음)
  누가 찍었는지, 써도 되는지 확인되지 않았다. 그림은 비공개 시안 캔버스의 "앱 아이콘 시안 · 사진에 가장자리 처리" 보드에만 있다.
- **실제 로고로 쓰려면 사진 권리가 필요하다** — 직접 찍은 사진, 구매한 사진, 허락받은 사진.
- 처리하면서 손댄 곳: 사진 틀에 잘린 윗머리를 둥글게 메웠고, 구글 표시를 지웠다. 오른쪽 귀 끝과 목은 사진 틀에서 잘려 있어서
  아이콘 칸 밖으로 나가게 놓았다.
- 처리 스크립트는 [photo-edge/](photo-edge/)에 있다. 사진만 바꿔 다시 돌릴 수 있다(사진은 저장소 밖에 둔다).

  ```bash
  pip install opencv-python-headless numpy
  ```

  ```bash
  cd design/logo-drafts/photo-edge && CHI_PHOTO=/경로/사진.png python3 final.py
  ```

  `out/`에 네 장이 나온다(저장소에는 올리지 않게 막아 둠). 스크립트 안의 숫자는 11/14에 받은 사진에 맞춘 값이라,
  다른 사진이면 `base.py` 머리말에 적힌 값들을 다시 맞춰야 한다. `coin-blank.png`는 1번에서 그린 동전의 빈 판이다.

## 고른 뒤 할 일

- 고른 안으로 `icons/`의 PNG 넷(192, 512, maskable 512, apple-touch)을 다시 만든다. 앱 이름 변경과 같이 상표 확인 뒤에 한다.
- 60px까지는 눈과 이빨이 보이지만 32px 아래로는 동전 모양만 남는다. 브라우저 탭용은 얼굴만 크게 넣은 단순판을 따로 그린다.
- 상표를 확인할 때 같이 볼 것: 금화 안의 개 그림은 도지코인을 떠올리게 한다("코인 주는 앱"으로 오해받을 수 있음).
- 사진 판(2번)으로 가면: 사진 권리부터 확인하거나, 직접 찍은 치와와 사진으로 바꿔 다시 처리한다.
