# 로고 시안 (아직 고르지 않음)

2026-11-14. 가르시아가 "성난 치와와를 로고로" 하자는 추천에 동의해서 만든 시안이다. 세 갈래를 해 봤고, 지금 가는 쪽은 3번이다.
**아직 안을 고르지 않았고 앱에는 넣지 않았다** — `icons/`와 `manifest.json`은 그대로다.

| | 갈래 | 상태 |
|---|---|---|
| 1 | 동전에 그린 판 (도지 동전 풍) | 앞 시안으로 남김 |
| 2 | 사진에 가장자리 처리한 판 | **쓰지 않음** (사진 권리 미확인) |
| 3 | **새로 그린 도장 판** (갈색 한 색) | 지금 가는 쪽 — 가르시아 "2번으로 가자 그려봐" |

나란히 비교한 보드는 [왈슨 화면 시안 캔버스](https://claude.ai/artifact/DbRJMTbicpqPWmeXoPo2JY)(비공개) 맨 아래 줄에 있다:
"앱 아이콘 시안 · 새로 그린 도장 치와와", 그 오른쪽에 앞 시안 둘.

## 3. 새로 그린 도장 판 (지금 가는 쪽)

사진 판의 '선만' 안이 마음에 든다는 말에, 사진을 쓰지 않고 같은 느낌으로 새로 그린 것이다.

| 파일 | 무엇 |
|---|---|
| `chi-stamp-side.svg` / `.png` | 옆얼굴 — 입을 벌리고 옆을 노려봄 (시안 A안) |
| `chi-stamp-front.svg` / `.png` | 정면 — 큰 귀 둘, 성난 눈, 드러낸 이빨 (시안 B안·C안) |
| `chi-stamp-side-ink.svg`, `chi-stamp-front-ink.svg` | 속을 칠하지 않고 잉크만 (시안 D안, 도장·키링·스티커용) |
| `stamp-src/` | 그림의 원본(파이썬으로 SVG를 만든다)과 PNG로 뽑는 스크립트 |

- 바탕 없이 그림만 들어 있다(400×400 기준, PNG는 960×960 투명 바탕). 시안에서는 노란 바탕 `#f7c84a`, 앱 색 바탕 `#b8563a`,
  크림 종이 `#fffaf3`에 올려 봤다. 잉크 `#5a3210`, 속 `#fff2c8`.
- **사진 권리 문제가 없다.** 받은 사진이나 다른 그림을 본뜨지 않고 새로 그렸다. 다만 상표로 등록하려면 비슷한 그림이 이미
  등록돼 있는지는 따로 확인해야 한다.
- 만든 방식: 흑백으로 그린 뒤 SVG 필터로 가장자리를 살짝 흔들고(손으로 판 도장 느낌) 잉크 한 색으로 바꾼다.
  이 필터는 브라우저마다 조금 다르게 그려질 수 있어서, **기준 그림은 PNG**다(크롬으로 그린 것).
- 고쳐 그리려면 `stamp-src/stamp.py`의 좌표를 고치고 다시 뽑는다.

  ```bash
  cd design/logo-drafts/stamp-src && python3 stamp_export.py ..
  ```

  ```bash
  cd design/logo-drafts/stamp-src && node svg2png.js .. chi-stamp-side chi-stamp-front
  ```

  두 번째 줄은 Playwright가 필요하고 4배 크기(1600px) PNG를 만든다. 시안의 960px는 그것을 줄인 것이다.
- 작게 줄이면: 48px까지는 눈과 이빨이 보이고, 32px 아래로는 정면이 더 잘 버틴다. 16px에서는 귀 모양만 남는다.

## 1. 동전에 그린 판 (앞 시안)

| 파일 | 무엇 |
|---|---|
| `chi-coin-front.svg` | 금화 속 정면 얼굴 |
| `chi-coin-side.svg` | 금화 속 옆얼굴 |

- 손으로 쓴 SVG다. 가르시아가 보낸 치와와 사진과 도지 동전 그림은 따라 그리거나 겹쳐 그리지 않았다(사진·밈 그림의 저작권).
- 색: 선 `#5a3210`, 동전 테 `#f6c244`, 동전 안 `#ec9c2c`, 동전 옆면 `#c47d1c`, 털 `#f9d05c`, 밝은 털 `#fff2c8`.
- 금화 안의 개 그림은 도지코인을 떠올리게 한다("코인 주는 앱"으로 오해받을 수 있음).

## 2. 사진에 가장자리 처리한 판 (쓰지 않음)

가르시아: "이걸 차라리 그냥 엣지처리만 해봐" → 받은 사진을 그대로 써서 넷을 만들었다(사진 + 테두리 · 색면 + 선 · 선만 · 금화에 넣기).

- **쓰지 않기로 했다.** 사진이 인터넷에서 가져온 것으로 보이고(왼쪽 아래에 구글 이미지 검색 표시가 있었음) 누가 찍었는지,
  써도 되는지 확인되지 않았다. 필터를 걸어도 원본의 윤곽·눈·이빨이 그대로 겹치면 원작자 허락이 필요한 2차적저작물이다
  (저작권법 136조·140조, 상표법 92조. 스톡 사진은 사도 보통 로고·상표로는 못 쓴다).
- 그림 파일은 이 저장소에 넣지 않았다. 비공개 캔버스의 앞 시안 보드에만 있다.
- 처리 스크립트는 [photo-edge/](photo-edge/)에 남겼다. 직접 찍었거나 허락받은 사진이 생기면 다시 돌릴 수 있다.

  ```bash
  pip install opencv-python-headless numpy
  ```

  ```bash
  cd design/logo-drafts/photo-edge && CHI_PHOTO=/경로/사진.png python3 final.py
  ```

  스크립트 안의 숫자는 11/14에 받은 사진에 맞춘 값이라, 다른 사진이면 `base.py` 머리말에 적힌 값들을 다시 맞춰야 한다.

## 고른 뒤 할 일

- 고른 안으로 `icons/`의 PNG 넷(192, 512, maskable 512, apple-touch)을 다시 만든다. 앱 이름 변경과 같이 상표 확인 뒤에 한다.
- 브라우저 탭용(16~32px)은 귀와 눈만 남긴 단순판을 따로 그린다.
- 상표 확인 때 같이 볼 것: 비슷한 치와와 그림 상표가 이미 있는지.
