# 로고 시안 (아직 고르지 않음)

2026-11-14. 가르시아가 "성난 치와와를 로고로" 하자는 추천에 동의하고, 도지 동전 풍으로 그려 보라고 해서 만든 시안이다.
**아직 고르지 않았고 앱에는 넣지 않았다** — `icons/`와 `manifest.json`은 그대로다.

| 파일 | 무엇 |
|---|---|
| `chi-coin-front.svg` | 정면에서 이를 드러낸 얼굴 (시안 A안·C안) |
| `chi-coin-side.svg` | 옆을 보며 입을 벌린 얼굴 (시안 B안) |

- 두 파일 모두 바탕 없이 동전만 들어 있다(400×400 기준). 시안 보드에서는 노란 바탕 `#f7c84a`(A·B안)와 앱 색 바탕 `#b8563a`(C안)에 올려 봤다.
- 나란히 비교한 보드: [왈슨 화면 시안 캔버스](https://claude.ai/artifact/DbRJMTbicpqPWmeXoPo2JY)(비공개)의 "앱 아이콘 시안 · 으르렁 치와와 동전".

## 그린 방식

- 손으로 쓴 SVG다. 가르시아가 보낸 치와와 사진과 도지 동전 그림은 따라 그리거나 겹쳐 그리지 않았다(사진·밈 그림의 저작권).
  치와와에서는 큰 귀·툭 튀어나온 눈·드러낸 이빨, 동전에서는 굵은 갈색 선·금색 면·두께가 보이는 옆면이라는 특징만 가져왔다.
- 색: 선 `#5a3210`, 동전 테 `#f6c244`, 동전 안 `#ec9c2c`, 동전 옆면 `#c47d1c`, 털 `#f9d05c`, 밝은 털 `#fff2c8`, 귀 안 `#f4a983`, 입 안 `#5c1f16`.

## 고른 뒤 할 일

- 고른 안으로 `icons/`의 PNG 넷(192, 512, maskable 512, apple-touch)을 다시 만든다. 앱 이름 변경과 같이 상표 확인 뒤에 한다.
- 60px까지는 눈과 이빨이 보이지만 32px 아래로는 동전 모양만 남는다. 브라우저 탭용은 얼굴만 크게 넣은 단순판을 따로 그린다.
- 상표를 확인할 때 같이 볼 것: 금화 안의 개 그림은 도지코인을 떠올리게 한다("코인 주는 앱"으로 오해받을 수 있음).
